# SyncBridge Integrations — Website

A responsive static website for an API integration and business automation service.

## Files
- `index.html` — page content, metadata and contact form
- `styles.css` — responsive styling
- `script.js` — mobile navigation, current year and email enquiry form

## Before you publish
1. Search `index.html` for `SyncBridge Integrations` and replace the brand name if you choose a different name.
2. Replace `hello@yourdomain.co.za` in BOTH `index.html` and `script.js` with your real business email address.
3. Review every service and claim. Remove anything you do not currently offer.
4. Add your actual business details and legal/privacy information if needed.
5. Test the site on a phone and desktop.

The contact form opens an email draft in the visitor's email app. It does not send form data to a server or store submissions. For a website contact form that submits directly without opening an email app, connect a form service or backend.

## Preview locally
Double-click `index.html` to open it in a browser. For a local server, open a terminal in this folder and run:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish for free using Netlify Drop
1. Visit https://app.netlify.com/drop
2. Sign in or create an account.
3. Drag the extracted website folder (the folder containing `index.html`) into the drop area.
4. Wait for Netlify to publish and provide a public URL.
5. Open that URL on your phone to test it.
6. You can connect a custom domain later in Netlify's domain settings.

You can also publish with GitHub Pages by uploading the three website files to a repository and enabling Pages in repository settings.

## Important
- The brand name and email address are placeholders, not a registered company or verified contact details.
- The website does not include client testimonials, certifications, pricing promises or claims of guaranteed results.
- Use a real email address before publishing.
